Bug Fixes

I worked on a number of bug fixes during my first work term at Brock. Those bugs exposed me to different features and systems within both the mobile and web applications, and they gave me experience investigating issues that ranged from business logic problems to user interface defects.

Container Auto-Creation Duplication Check

One of the more involved bugs I worked on was a duplication check for the web client container auto-creation configuration page. The web client allows users to automatically create certain ULD, cart, or bulk-hold containers when a flight with a specific airline and aircraft is created. This is useful when those flights regularly require the same container setup.

The bug was that the system did not prevent users from creating containers with the same name, or from assigning multiple containers to the same aircraft position for the same airline and aircraft combination. I implemented checks against the existing configured containers to prevent those conflicts. The more difficult part was handling cases where the user made multiple pending edits across different containers at the same time. To solve that, I created a virtual version of the container list that included all pending changes and ran the duplication checks against that state.

French Mobile Formatting Fixes

Another bug I fixed involved formatting issues in several parts of the mobile application caused by certain French translations. Brock develops the application in English, but the product also supports French, Portuguese, and Spanish.

To fix the issue, I updated the AXML layout code and some of the frontend C# code so the screens could better accommodate longer French strings. Those changes had to be made carefully to preserve the working layouts for the other supported languages.
