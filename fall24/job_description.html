My job at Armour Technology Solutions during the fall term was very similar to my experiences in the summer term. I spent the vast majority of my time working on custom software development, either creating new code or fixing/adding features to existing projects. My schedule would sometimes vary greatly day-to-day, but other times I would be working on one project for one or more weeks before I would work on anything else. For the smaller projects I worked on, my supervisor would usually verbally tell me what I was to add/fix, and when I was finished I’d go report back. For larger projects, my supervisor and I would join a virtual meeting where I would be shown what to do and why I was doing it. As I was generally developing the project from scratch, I wouldn’t be given any strict requirements, but rather a list of features that were required. When I was satisfied with what I had, a meeting would be set up where I would show off what I had completed which would also have me receive feedback on what was and was not liked about the program I came up with. From there I would make the necessary changes and another meeting would be scheduled and the process would be repeated.

I wrote all of my code in Visual Studio using C#, JavaScript, and HTML. I commonly used VPNs to access Microsoft NAV servers and SQL servers. Some of the projects that I worked on this term include an automated tool that runs daily and reads BOL documents from a remote server and enters them into a SQL database, a program that reads invoices and BOL records from a fuel company’s email account and enters them into a NAV system, and a program which allows customers of a filtration company to create and submit orders online.
