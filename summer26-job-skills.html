Skills Developed

Job Skills

This page summarizes the technical and transferable skills I strengthened during the term. Detailed reflections on the learning goals themselves are in Achieving My Goals.

Tracking work items, priorities, and release-planned bugs was an important part of how I organized my work.

Technical Skills

  • Use Visual Studio to write and debug C#, JavaScript, and AXML code across mobile client and API changes.
  • Investigate existing patterns and mutation flows before implementing features, so new work fits the codebase cleanly.
  • Use SharePoint and TFS to query boards, review planned-release and regression bugs, and sort work by priority and severity.
  • Create pull requests, review teammates' PRs more deliberately, leave clarifying comments, and move changes through approval.
  • Use AI tools to explore implementation options, locate relevant code, and draft tests, while still validating changes carefully myself.
  • Run regression tests during release cycles and document results through comments and bug reports.

Transferable Skills

  • Work more independently by investigating how to implement a feature myself and deciding a sensible order for related tickets.
  • Improve bug judgment by evaluating multiple possible solutions and distinguishing defects from as-designed behaviour, configuration issues, and user problems.
  • Manage time more deliberately during time-sensitive release work through time boxing and earlier communication when progress is at risk.
  • Ask better questions earlier around design decisions, rather than waiting until rework becomes necessary.
  • Think more carefully about production impact, including feature toggles, customer-facing release branches, and compatibility between newer APIs and older clients.
